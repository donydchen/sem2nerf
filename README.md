# Sem2NeRF Project Page

This branch holds the static project page for **Sem2NeRF: Converting Single-View Semantic Masks to Neural Radiance Fields** (ECCV 2022).

The page is published by GitHub Pages from this `gh-pages` branch and lives at <https://donydchen.github.io/sem2nerf/>.

Paper: <https://arxiv.org/abs/2203.10821>

The research code lives on the `main` branch of this same repository.

## Notes

This is a plain HTML/CSS/JS site. The empty `.nojekyll` file at the root tells GitHub Pages to skip Jekyll processing and serve the files exactly as they are.
